## antislop

For UI work, read `DESIGN.md` for visual direction first, then `antislop.md` (core) as the filter. For copy, accessibility, mobile layout, or code-comment work, read `antislop.md` (core) before starting.

Only the core filter is installed here. The optional skill folders (`skills/antislop-ui`, `skills/antislop-copywriting`, `skills/antislop-human`, `skills/antislop-layoutmobile`, `skills/antislop-code`) are not present in this project; do not reference them until they are added.
